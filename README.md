# Гофермарт

Накопительная система лояльности для интернет-магазина. HTTP API на Go принимает номера заказов, получает расчёт начислений от внешнего сервиса и позволяет тратить накопленные баллы на новые заказы.

## Технологии

| Технология | Версия | Назначение |
| --- | --- | --- |
| Go | `1.26.5` | HTTP API и фоновый опрос сервиса начислений. |
| PostgreSQL | `18.7-bookworm` в Compose | Хранение пользователей, заказов, балансов и списаний. |
| Docker Compose | Проверено на `v5.0.2` | Запуск локальной базы. |
| `pgx` | Выбрана ветка `v5` | Доступ к PostgreSQL из Go. |
| `golang-migrate` | Проверено на `v4.20.1` | Применение и откат SQL-миграций. |

## Локальный запуск

Понадобятся Go, Make, Docker Compose и CLI `migrate`. Из корня проекта выполни:

```sh
make compose-up
make migrate-up
make run
```

Локальная база доступна на `127.0.0.1:55432`. Makefile использует её по умолчанию. Для другой базы задай `DATABASE_URI`.

`make test` запускает тесты, `make build` собирает бинарник, `make migration-create NAME=add_example` создаёт пару SQL-файлов, а `make migrate-down` откатывает последнюю миграцию.
